# 实现契约

MoonEDN 是 EDN 值读写与工具库。公共值保留列表/向量、任意键映射、集合、字符、符号、关键字和带标签值。整数与精确十进制使用字符串存储，避免跨后端舍入。公共数组由调用方持有；库的编辑/转换结果必须脱离输入，不把可变数组宣称为不可变对象。

reader 使用 Unicode scalar 索引，明确区分 UTF-16 code unit 和字节偏移；每次读取有输入、深度、节点、token 和容器上限。所有枚举构造也须经过 writer 校验；用户构造的循环数据受深度预算约束。discard 读取语法但不执行用户回调。

数字、符号、读取、相等键、写入、格式化、JSON、标签、路径、编辑各层分开；核心纯 MoonBit，不启动进程或访问网络。无网络和文件依赖的示例能够运行于四种 Moon 后端。

验收采用手写边界测试、edn_format 独立差分、语义与格式往返性质、失败状态不变、外部消费者与真实 CI。未知标签默认以原始标签和值的结构相等；需要其它等价语义时应由应用先规范化。
