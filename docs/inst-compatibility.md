# EDN 标准时间值兼容方案

兼容目标是 edn-format/edn 的内置 `#inst` 与 RFC 3339 §§4.3、5.6–5.8、Appendix D。原生值继续用 `Tagged("inst", Text(...))` 保存原始字符串；不使用宿主语言 `Date`，避免毫秒截断、年份范围收缩与闰秒折叠。此说明覆盖标准时间值，不声称覆盖全部 Clojure reader 扩展。

| 标准要求 | 处理方式与验证入口 |
| --- | --- |
| 四位年份、公历月份和闰年 | 接受 `0000..9999`；按公历公式计日，年份 0000 的除法不经过负数；世纪与端点回归 |
| 完整时间、大小写 T/Z、数值偏移 | 校验时分秒与偏移字段；按分钟归一化到 UTC，允许跨日、跨年；435 个生成案例 |
| `-00:00` | UTC 已知、本地偏移未知；等价键按 UTC 比较，原字符串保留未知偏移标记；writer/pretty/tagged JSON 验证 |
| 非空小数秒 | 限额内逐位保存和比较，不转换浮点，等价键仅删尾零；超出限额由统一资源错误拒绝 |
| 正闰秒 `:60` | 对偏移归一化后核验已公告 UTC 事件，包括非整小时时区和跨日写法；与 `:59` 及次日 `:00` 保持不同 |
| 负闰秒时末秒为 `58` | 事件表保存有符号调整；解析器在调整为 -1 时拒绝被删掉的 `:59`。目前 IERS 表无负闰秒，实测范围限于现有正事件及此校验分支的单元测试 |
| EDN 相同时间戳等价 | `equivalent`、map 查找、map/set 重复校验共用同一完整等价键；无效手工 tag 也不能绕过 writer 校验 |

`instant_key` 的返回类型维持 `(Int64, String)`，普通秒的已有结果保持不变。对闰秒，第一项为前一普通秒的 POSIX 秒，第二项加 `leap:` 前缀；该前缀与任何纯数字小数互斥。此 API 是等价键，不提供排序、持续时间或 TAI 转换语义。所有公开读写路径仍保留原时间文本。

## 闰秒数据与更新

事件事实来自 [IERS 官方 Leap_Second.dat](https://hpiers.obspm.fr/iers/bul/bulc/Leap_Second.dat)，本次核对版本为 Bulletin C 72（2026 年 7 月），有效期至 2027 年 6 月 28 日；1972 年初的基线偏移不是插入事件，其后的 27 次变化均为 +1。库内只保存事件时间与方向，不复制公告正文。内置表用于离线确定性解析，不查询本机时区或网络。

标准要求闰秒先公告再使用，未来 `:60` 不应猜测。IERS 如公布新正/负事件，维护者应更新 `tags.mbt` 中的带符号 UTC 边界、生成器中的正事件日期和相应用例，重新核对表。当前没有历史负事件，不能把模拟分支测试称作真实负事件互通证据。

```sh
# 从上述 IERS 官方链接下载最新文件到仓库外，然后：
python tools/generate_inst_vectors.py --check --iers-file /path/to/Leap_Second.dat
moon test --deny-warn
moon run examples/inst
```

生成器使用 Python 标准库公历计算普通秒预期值，使用 IERS 事件事实派生各偏移的闰秒输入；测试文本为本项目自有生成，不复制第三方测试集。离线 CI 重算并校对已提交的 435 个预期。联网核对用于发现公告变化，不把上游连接失败误记成解析失败。

## 不属于本标准的输入

不接受缺少时间或偏移的日期、扩展年份、`24:00:00`、逗号小数、缺位偏移和附带垃圾字符。RFC 3339 的规范语法使用 `T/t`；可选的空格分隔扩展未启用。资源上限继续适用于所有标准值，并非按特定时间类别禁用功能。

规范来源：[EDN 内置标签与等价语义](https://github.com/edn-format/edn)、[RFC 3339](https://www.rfc-editor.org/rfc/rfc3339)。
